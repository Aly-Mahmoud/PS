Important libraries

<stdio.h>
Purpose: Standard Input and Output library.
Key Functions: printf, scanf, fprintf, fscanf, fgets, fputc, fopen, fclose, fflush.
Uses: Handling console input/output, file operations, and formatted text.

fscan(str, sizeof str, stdin);
    it takes in consideration the enter in your keyboard as a character

<string.h>
Purpose: String handling and manipulation.
Key Functions: strlen, strcpy, strncpy, strcmp, strcat, strncat, memcpy, memset.
Uses: Manipulating and operating on character arrays, copying and comparing strings, memory operations.
